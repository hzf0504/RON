# RON × 喵服 WG 助手 0.3 延迟记录测试版

用于 Windows x64 + Steam 版 Ready or Not、同版本 2～5 人私用。**这是含实验性候选适配模块的测试软件，尚未证明真实对局已通过喵服 WG，也未证明可以改善卡顿。**

交付为独立小软件，`RonWgAssistant.exe`、`RonWgProbe.dll` 和 `RonLatency.dll` 保持在同一个解压目录。不要把 DLL 放进游戏的 Binaries、Steamworks 或 RedpointEOS 目录，不需要覆盖任何游戏文件。

## 实时延迟记录

打开助手后，“延迟记录”页会自动等待游戏。发现受支持的游戏构建后开始记录，游戏退出时结束并保存。使用普通 Steam 启动和现有 WG 适配启动均可触发记录。

房主按每条客机连接分别记录，客机显示“本机 ↔ 房主”。表格显示 RTT 和该采样秒内的峰值，单位为 ms。点击不同连接可切换曲线，实时显示最近两分钟的按秒均值和采样范围，原始有效样本逐条保存在本机。三秒没有新样本时显示“暂无新数据”，缺失区间在曲线中断开。

顶部下拉框可选择历史记录并查看全程曲线。“导出此记录的脱敏 ZIP”会导出当前所选记录，玩家名称会替换为包内一致的标签。原始数据保存在 `sessions` 的 `*-latency-*` 文件夹，每个日志段达到 16 MB 后继续新建一段，旧段保留。

采集来源为游戏引擎 `PlayerState::UpdatePing` 的有效输入，更新频率由游戏决定。当前构建的入口和玩家字段已静态核对，采集、恢复、曲线和回看已完成离线验证，真实多人对局的读取正确性仍待实测。记录中的 `OfflineFixture` 表示离线验证数据。

## 界面分区

以下设置和手动操作位于“联机诊断”页。

| 分区 | 功能 |
| --- | --- |
| 连接设置 | 确认游戏根目录，选择活动的喵服 WG 网卡，填写朋友的虚拟 IPv4。刷新网卡时会保存本机网络快照。 |
| 测试信息 | 填写双方约定的测试编号、各自角色和网络类型，便于把双方日志对应到同一轮。 |
| 游戏观测 | 观测已运行的游戏，或在游戏完全退出后从 Steam 启动并尝试实验性 WG 适配。 |
| WG UDP 测试 | 生成或填写双方共用的诊断口令，启动应答，测量 20 秒的隧道延迟和丢包。结果仅对应助手的测试流量。 |
| 事件标记 | 手动标记进房、切图、卡顿的时间点，可附简短备注。 |
| 运行状态与恢复 | 查看连接提示和游戏观测计数，停止当前观测或 UDP 测试。完整恢复游戏原连接需要退出并重启游戏。 |
| 运行日志与导出 | 查看本次操作、错误和结果，导出当前或历史会话的脱敏 ZIP。 |

窄窗口会将设置和测试区排成单列，底部仍可查看日志、停止操作和导出。

## 现在不联网也能做什么

1. 双击 `RonWgAssistant.exe`，填写共同测试编号、角色及网络类型。
2. 点“刷新网卡并保存快照”，记录本机接口状态；不启动游戏，也不向朋友发包。
3. 有操作失败时，错误会自动记录。可以点“记录时间点”补充说明。
4. 点“导出脱敏诊断 ZIP”，将 `exports` 中生成的 ZIP 回传即可。重启软件后可用“导出历史会话”选择之前的日志。

## 后续联机测试

双方自行使用喵服客户端 `nya-client` 连接同一网络，然后操作助手。保持游戏跨平台开启，使用原有 Steam 邀请。助手不登录喵服、不读取隧道配置或密钥、不创建中继、不自动改变系统路由。

- “观测当前游戏”：记录 EOS 接收轮询、收发调用、UDP 端点及预测路由，不筛选网卡。
- “从 Steam 启动并尝试 WG 适配”：实验性地让 EOS 的 `GetAdaptersAddresses` 结果仅包含所选 WG 网卡。数据可靠性、加密、连接生命周期仍由原 EOS SDK 处理；EOS 可能继续使用公网/官方中继。
- “测量 WG UDP”：仅是助手的认证 UDP 测试，与真实游戏流量分开记录，不能作为适配成功证明。
- “停止 / 恢复原连接”：请求恢复进程导入表。**退出并重启游戏**才能清除 SDK 缓存和驻留模块，完整恢复原连接。

兼容性目录当前锁定本机观测的 Steam Build `25784851` 和游戏/EOS 文件 SHA-256。其他构建会拒绝附加；请回传错误日志，不要手改哈希绕过。现有 Steam/DLC 补丁只核对文件哈希，不读取内容、不覆盖、不分发。

## 日志与隐私

`sessions` 保存本机原始诊断日志，包含 IP、进程号、版本和部分本地路径；不记录游戏包内容、WG 密钥或账号令牌。`exports` 中的 ZIP 自动将 IP 替换为包内一致的标签，隐藏绝对路径和自定义网卡名。原始日志保留在本机。

默认诊断包仅包含选中会话的助手文件，不包含整个游戏目录、游戏存档、原始游戏日志、抓包、程序二进制或喵服目录。不要把诊断口令、账户信息写进备注。详情见 `LOG_FORMAT.md`。

## 发给测试人员

发送 `releases` 中生成的 `RONWG-0.3.0-experimental-win-x64.zip` 和同名 `.sha256.txt`。压缩包已含运行时，测试者无需安装 Python、Visual Studio 或 .NET SDK。必须完整解压再启动；不要只发 EXE。完整步骤见 `TESTER_GUIDE.md`。

## 开发与本机验证

在项目工作区的 PowerShell 中执行：

```powershell
.\scripts\build.ps1 -SelfContained
.\scripts\test.ps1 -Offline
.\scripts\package.ps1
```

`-Offline` 仅用合成 SDK、文件及本机接口枚举验证日志/恢复，不启动真实游戏、不执行 UDP 发包或联网测试。不带 `-Offline` 的旧测试包含回环 UDP 与独立测试进程注入，应在适合测试时运行。

普通界面不要求管理员权限。只有可选的精确防火墙规则和 PktMon 捕获脚本需要管理员权限；不关闭整个防火墙。软件未做代码签名；若被系统或安全软件阻止，请记录提示交回开发者，不要求绕过保护。
